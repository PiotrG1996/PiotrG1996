## About Me

I am a **Robotics Software Engineer** focused on developing autonomous robotic systems through the integration of robotics software, perception, machine learning, and embedded computing.

My work connects algorithms with sensors, simulation environments, and physical hardware to develop integrated robotic solutions. I am particularly interested in translating theoretical approaches into reliable, maintainable engineering implementations.

My approach combines **modular software architecture, algorithm development, simulation-based validation, and hardware integration**. I value reproducibility, systematic testing, clear technical documentation, and dependable system behavior.

This portfolio presents selected projects in mobile robotics, computer vision, edge AI, and embedded data acquisition.
